# TopChain Fresh — company website

Static company website: home, trading, products, logistics, AI Lab, future solutions and contact.

Photography is served locally; source notes are in PHOTO_CREDITS.md. AI dashboard graphics are concept illustrations, not live operational data. Contact inquiries open the visitor’s mail application for review and sending.

Publish the main branch root with GitHub Pages. No build tools, API keys, database or recurring application workflows are required.

Personal brands, RealFamily, news, markets, recipes and English-learning pages are intentionally excluded from this company deployment; their original archives remain preserved separately for a future domain.

The custom domain is www.topchainfresh.com. Configure it in Pages and verify ownership before changing DNS. Preserve the existing DNS email records.
